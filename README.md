# Business Statistics — Interactive Applets

Interactive explorers for the First-Year MBA **Business Statistics** course at BITSoM.
Built as single-file HTML — no installation, no login, works in any modern browser.

## Open the applets (one click)

| Applet | Use it for | Session |
|---|---|---|
| [Coin-Toss Simulator](https://parasuram-bala.github.io/Applets-Business-Statistics/coin_toss_simulator.html) | Flip n coins many times — the count-of-heads distribution fills the binomial curve, and the heads proportion settles on p (law of large numbers) | 2–3 |
| [Binomial Explorer](https://parasuram-bala.github.io/Applets-Business-Statistics/binomial_explorer.html) | Yes/no counts over n trials — garment-QC batches, checkout conversion | 3 |
| [Poisson Explorer](https://parasuram-bala.github.io/Applets-Business-Statistics/poisson_explorer.html) | Counts per time or space window — call-centre arrivals, steel-sheet defects | 3 |
| [Normal Explorer](https://parasuram-bala.github.io/Applets-Business-Statistics/normal_explorer.html) | Continuous outcomes — delivery-time SLAs, fill weights | 3 |
| [Sampling Distribution Explorer](https://parasuram-bala.github.io/Applets-Business-Statistics/clt_simulator.html) | Watch the sampling distribution of x̄ build as you draw samples — the CLT in action, even from a skewed population | 4 |
| [Confidence-Interval Simulator](https://parasuram-bala.github.io/Applets-Business-Statistics/ci_simulator.html) | Draw repeated samples and see what fraction of 95% intervals actually catch the true mean — what "confidence" really means | 4 |

## How to use

1. Click a link above — the applet opens in your browser.
2. Pick a business scenario (chips at the top right), set the parameters, and read the
   result off the chart. Every applet has a "plain" chip for the abstract version.
3. Suggested first moves:
   - *Coin-Toss* — Toss 1,000 and watch the bars fill the binomial curve; then set n = 1 and watch the heads proportion settle on p.
   - *Binomial / Poisson / Normal* — pick a scenario, choose a probability query, and read the highlighted region.
   - *Sampling* — Draw 1 sample a few times, then Draw 1,000; change n and watch the spread of x̄ shrink.
   - *Confidence-Interval* — Draw 200 samples and read the % of intervals that caught μ; switch the confidence level and see it track.

**Offline use:** download any `.html` file (Code → Download ZIP) and double-click it —
everything runs locally, no internet needed.
